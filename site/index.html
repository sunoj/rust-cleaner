Features

Menu Bar

Live in the macOS menu bar. One click to open, scan, and clean.

Safe by default

Only removes well-known artifact dirs. No source or configs touched.

Age filter

Clean only old artifacts (e.g. >7 days) to keep recent builds.

Configurable roots

Point at your dev folders; exclude paths via config.

Rusty Icon

Status bar icon gets rustier as disk usage grows — visual pressure to clean up.

Multi-type Scanning

Scans Rust target/, node_modules/, .next/, dist/, build/, and temp cc-target-* dirs.

Install

  1. Clone and enter the repo: git clone https://github.com/sunoj/wd-40 && cd wd-40
  2. Install the app: make install
  3. Optional — start at login: make autostart

Config

Config path: ~/.config/wd-40/config.toml

~/.config/wd-40/config.toml
scan_dirs = ['~/Develop', '~/Projects']
artifact_types = ['target', 'node_modules', '.next', 'dist', 'build']
max_age_days = 7
max_depth = 5
auto_clean_hours = 0
